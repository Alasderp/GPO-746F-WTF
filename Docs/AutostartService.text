1. Save service script to below location

/home/alasdair/.config/systemd/user/myscript.service

2. To enable the script at boot-up

systemctl --user daemon-reload
systemctl --user enable RotaryPhone.service

sudo reboot

OR

systemctl --user start RotaryPhone.service

3. To disable the service

systemctl --user stop RotaryPhone.service
systemctl --user disable RotaryPhone.service

4. To check the status of a service

systemctl --user status RotaryPhone.service
